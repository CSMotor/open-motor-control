在 Simulink 里把电流环调得又快又稳，一上实物却啸叫、震荡，甚至烧功率管。做电机控制的人，大多遇到过这种情况。

原因是仿真太理想了。连续域仿真里，PWM 和输出电压是理想的线性关系，芯片没有一拍延迟，逆变器没有死区，传感器没有噪声。真实的硬件不是这样。

很多人做仿真，只是初步验证算法能不能跑通，真要下结论还得靠实验。把这些真实的硬件环境也搬进 Simulink，让仿真尽可能贴近实物，很多问题在电脑上可以先暴露出来，不必等到打板、上电、反复调试才发现。制造再优秀的硬件，也难免有误差和噪声；仿真把这些误差还原得越真实，结论越可信，迭代越快。

本文从电机控制原理讲起，梳理一套更贴近实际控制器的 Simulink 永磁同步电机仿真该怎么搭，把真实硬件和连续域仿真之间的差距一点点补上。

## 1、电机控制算法基本原理

搭仿真之前，先得搞清楚控制器里跑了哪些算法。

典型的电机控制框图如下图所示。从原理上看，整个电控算法除了外设之外，包含 6 个关键的算法模块：

1. Clarke 变换模块；
2. Park 变换模块；
3. 电流调节器；
4. 转速调节器；
5. 逆 Park 变换模块；
6. SVPWM 模块。

这些是双闭环速度控制的核心算法模块，都运行在电机控制器中，也是仿真里首先要复现的对象。

![](images/Pasted%20image%2020261102160851.png)

> 图 1：典型的永磁同步电机双闭环矢量控制框图。

但光有这些算法还完不成电机控制，还需要各种外设。人要走路，光有大脑不够，还得有腿脚和眼睛。因此还要引入另外三个关键模块：

1. 电流传感器、位置/速度传感器等各类传感器及其解析模块，好比我们的眼睛等感官；
2. 驱动电路及三相逆变器，好比我们的手脚；
3. 电源模块。电源模块通常我们按稳定的直流来考虑，但实际上要复杂得多。

算法是大脑，外设是五官和手脚。仿真里我们往往只搭好了大脑，把五官手脚全当成理想器件。理想仿真和真实硬件的差距，从这里开始。

## 3、真实硬件与连续域仿真的差异

真实硬件和连续域仿真的差异，主要有这四点。

1. **PWM 一拍延迟**：真实的控制芯片存在 PWM 一拍延迟，连续域仿真中没有这一拍延迟。
2. **逆变器非线性**：驱动电路与三相逆变器存在死区、开通关断非线性等影响；而在连续域仿真中，PWM 与输出电压之间是纯粹理想的关系。
3. **电流采样误差**：电流传感器和真实电流之间存在差距，包括增益偏差、零漂偏差和采样底噪，底噪大小与硬件性能有关。此外，电流采样在一个载波周期中的位置，也会影响控制性能。
4. **速度信号滤波**：位置传感器的位置信号通常噪声不大，但速度信号需要由位置信号微分得到，因此一般要经过滤波后才使用。

仿真里需要尽可能的还原以上四点。

温度、负载特性变化带来的死区变化、PWM 计算精度等，暂时不考虑，先讨论这四个方面。

## 4、Simulink 内模拟芯片载波逻辑、中断触发模式及 PWM 一拍延迟

第一个是一拍延迟。讲延迟之前，先得把 拍 这个概念理解了。

数字控制器不是连续工作的，它按固定的节拍运行。每过一个控制周期，控制器执行一轮完整动作：ADC 采样电流和位置，算出占空比，写进 PWM 比较寄存器。这一轮动作的周期，习惯上叫一拍。在 PWM 里，一拍通常等于一个载波周期 $T_s$。

这轮动作由中断触发，触发方式有好几种。本文采用最常见的一种：载波计数器到固定位置时，由 PWM 硬件触发 ADC，比如 TI C2000 的 SOC、STM32 的 TIM 触发 ADC；ADC 转换结束后产生 EOC 中断，CPU 在中断里读取结果、计算、更新比较寄存器。在这种方式下，采样在中断之前已经完成，中断只负责读取和计算。控制的节奏本质上跟着 PWM 载波走，具体时序如下图所示。

![](images/Pasted%20image%2020261103121211.png)

采样和更新的模式，最常见的是单采样单更新：一个载波周期只采样一次、更新一次，通常在载波峰值或谷值时刻采样，算出的占空比要等到下一个载波周期才写进比较寄存器、改变输出。
![](images/Pasted%20image%2020261103120356.png)

以单采样单更新为例，控制芯片在本周期开始时刻算好占空比，写进比较寄存器，要到下一个载波周期，PWM 输出才真正改变。从算出电压指令，到电压真正作用到电机上，中间隔了一整拍。

写成式子，第 $k$ 个周期算出的占空比是 $d(k)$，实际作用到逆变器的是上一拍的：
$$d_{out}(k) = d(k-1)$$
连续域仿真里，控制器是连续的，电压指令给出后立刻生效，没有这一拍。仿真里电流环能调到很高的带宽，实物上却达不到。反馈通道多了一拍延迟，相位裕度被吃掉一部分。

Simulink 里复现中断触发和这一拍延迟：用离散的采样时间 $T_s$ 驱动整条控制链路，控制器输出和 PWM 模块之间串一个 Unit Delay（单位延迟）。

### 4.2 搭建基础的算法框架

按照第 1 节梳理的结构，控制算法一共六个模块：Clarke 变换、Park 变换、电流调节器、转速调节器、逆 Park 变换、SVPWM。这一篇重点讲怎么让模型贴近实际，底层算法的原理前面几篇已经讲过，这里不再展开推导，需要复习的同学可以回看前面的文章。（这里的电机参数用的是Simulink自带的电机预设模型05号，开关频率采用的是10kHz，后续会专门出一篇讲述参数化的文章。我们先用定参数的。）

**步骤六：在子系统中依次添加6个matlab function 模块；** 六个模块的输入输出如下：

1. Clarke 变换：输入三相电流 $i_a$、$i_b$、$i_c$，输出 $i_\alpha$、$i_\beta$；
2. Park 变换：输入 $i_\alpha$、$i_\beta$ 和电角度 $\theta$，输出 $i_d$、$i_q$；
3. 电流调节器：输入 d、q 轴电流误差，输出 $u_d$、$u_q$，d、q 各一路 PI；
4. 转速调节器：输入速度误差，输出 q 轴电流指令 $i_q^*$；
5. 逆 Park 变换：输入 $u_d$、$u_q$ 和 $\theta$，输出 $u_\alpha$、$u_\beta$；
6. SVPWM：输入 $u_\alpha$、$u_\beta$ 和母线电压 $U_{dc}$，输出三相占空比。

整条信号流是这样走的：速度误差送进转速调节器，得到 $i_q^*$；d 轴指令取 0，和 $i_q^*$ 一起送进电流调节器，算出 $u_d$、$u_q$；再经过逆 Park 和 SVPWM，变成三相占空比，送进 PWM。为了阅读流畅，六个模块的完整代码统一放在附录，需要直接取用的同学翻到文末即可。

### 4.3 构建载波生成器与触发信号

完成了触发架构和基础算法模块的搭建，下一步搭建载波生成器。载波是 PWM 的核心，前面 36 问系列的开篇讲过开关周期和载波周期的区别，也讲过不同的载波类型。电机控制里通常用等腰三角载波，波形如下图所示。

![](images/Pasted%20image%2020261103133954.png)

先构建这个载波信号。

载波模块本身是 STM32、DSP 这类 MCU 的外设，不参与控制算法的计算，所以不放在控制算法子系统里，在外部单独搭建。等腰三角载波是先增后减的波形，对应一个先按固定步长增加、再按固定步长减少的函数。这需要一个足够小的外部离散步长，所以要加入 powergui 模块，把离散步长设为载波周期的一千分之一。步长越小，载波的量化台阶越细。

**步骤七：** 加入 powergui 模块，设定外部环境的离散步长。开关频率取 10 kHz，先加入 powergui 模块。

![](images/Pasted%20image%2020261103134636.png)

**步骤八：** 加入 MATLAB Function 模块，编辑代码生成等腰三角波。要求输入可调，通过改外部输入就能改开关频率，也就是改载波周期，代码如下。

```matlab
function y = carrier(u)
%#codegen
persistent cnt dir
if isempty(cnt)
    cnt = 0;
    dir = 1;
end
Tdis = 1e-7;
n  = round(u/Tdis);
nh = n/2;

y = cnt/nh;

cnt = cnt + dir;
if cnt >= nh
    cnt = nh;
    dir = -1;
elseif cnt <= 0
    cnt = 0;
    dir = 1;
end
```

仿真前先把前面的算法模块注释掉，因为还没有输入，直接跑会报错。此时仿真，可以看到干净的等腰三角载波，周期 10 kHz，载波周期等于输入变量 0.0001。

![](images/Pasted%20image%2020261103135719.png)

这里要注意示波器的仿真步长。步长设置太大，看不到这么细的载波，容易采样失真。

**步骤九：** 构建触发信号。

到这里只搭好了载波，触发信号还没有。采样和中断都在载波的顶点触发，所以要在载波函数里加一个判定：cnt 到顶点 nh 时输出高电平，下一个步长就回到低电平，形成一个步长宽的脉冲。代码改动如下。

```matlab
function [y, trig] = carrier(u)

%#codegen
persistent cnt dir
if isempty(cnt)
cnt = 0;
dir = 1;
end

Tdis = 1e-7;
n = round(u/Tdis);
nh = n/2;

y = cnt/nh;
trig = (cnt == nh);

cnt = cnt + dir;
if cnt >= nh
cnt = nh;
dir = -1;
elseif cnt <= 0
cnt = 0;
dir = 1;

end
```

trig 接到 Trigger 子系统的触发输入上，触发就和载波同步了。触发点想放到谷值，把 trig = (cnt == nh) 改成 trig = (cnt == 0)。
仿真结果如下图所示：如果有兴趣的同学可以再构建一个触发的累加模块，看看最后累加的值是不是恰好等于预计的数目。

### 4.4 构建 PWM 生成器

控制算法最后输出的是三相占空比 $d_a$、$d_b$、$d_c$，还要把它们转成实际的 PWM 开关信号。三相逆变器有 3 个桥臂、6 个开关管，同一桥臂上下两个管子的驱动信号互补，所以三路占空比最后要变成六路互补的 PWM。

**步骤十：** 增加一个 MATLAB Function 模块，写入比较逻辑，代码如下。

```matlab
function y = fcn(carrier, dutyA, dutyB, dutyC)

%#codegen

ref = carrier;

CMPA = dutyA;

CMPB = dutyB;

CMPC = dutyC;

Ta1 = 0; Ta2 = 0;

Tb1 = 0; Tb2 = 0;

Tc1 = 0; Tc2 = 0;

if ref <= CMPA

Ta1 = 1; Ta2 = 0;

else

Ta1 = 0; Ta2 = 1;

end

if ref <= CMPB

Tb1 = 1; Tb2 = 0;

else

Tb1 = 0; Tb2 = 1;

end

if ref <= CMPC

Tc1 = 1; Tc2 = 0;

else

Tc1 = 0; Tc2 = 1;

end

y = [Ta1; Ta2; Tb1; Tb2; Tc1; Tc2];
```

比较逻辑有三点要说清楚。

第一，比较值直接取占空比。载波从 0 升到 1 再降回 0，载波高于占空比的时间是 $1-d$ 个周期，所以占空比 $d$ 越小，输出的 PWM 越宽。

第二，同一桥臂上下两个管子互补。代码里 `Ta1` 和 `Ta2` 始终一个为 1、一个为 0，分别对应上管和下管的驱动信号，六路输出依次是 A 相上下、B 相上下、C 相上下。

第三，输出高还是低，要和驱动板匹配。DSP 和 STM32 都能配置载波高于比较值时输出高还是低。大多数逆变器驱动是高有效，也有低有效的，仿真里必须和板子对上，否则开关管会反相动作。

搭好之后用示波器看效果。加一个偏置 0.5、幅值 0.2、频率 50 Hz 的 Sine Wave 当作测试调制波，用 Demux 把六路信号分开看第一路 PWM，再用 Mux 把调制波和载波放在一起对照。仿真可以看到：调制波处在下半周时，占空比比较小，输出 PWM 较窄；调制波处在上半周时，PWM 较宽，占空比比较大。PWM 生成到这里就完成了。
注意：这里有同学问了，为什么有的地方是CMPA = 1-dutyA？
这是我们在控制逻辑里面输出的占空比duty就是所期望的高电平持续的占比；下面比较的逻辑是反相的，那么上面就要反相一下。整体对上就行了，最终需要符合的就是占空比和高电平时间对齐就好。

### 4.7 模拟真实 MCU 的 PWM 一拍延迟

## 5、逆变器死区与非线性的模拟

第四节解决了Simulink 内模拟芯片载波逻辑、中断触发模式及 PWM 一拍延迟的问题。第五节就开始对逆变器非线性进行优化了。

理想情况下，PWM 占空比和输出电压是线性关系：$u = d \cdot U_{dc}$。真实的逆变器不是这样。

最典型的是死区。为了防止同一桥臂上下两个开关管同时导通、造成直通短路，驱动电路会在上下管切换之间插入一段死区时间 $t_d$。死区期间两个管子都关断，输出电压由相电流的方向决定，实际电压与理想占空比算出来的不一样。

一个桥臂的死区电压误差可以写成：
$$\Delta u = \frac{t_d}{T_s} U_{dc} \cdot \text{sgn}(i)$$
其中 $\text{sgn}(i)$ 是电流的符号。电流为正时实际电压偏低，电流为负时实际电压偏高，死区误差的大小和方向跟着电流走。

这带来两个后果。一是电流过零附近符号翻转，电压误差突然变号，电流波形上出现平顶畸变；二是三相的死区误差合到 dq 轴上，表现为 6 次谐波脉动，转速上能看到周期性的抖动。

除了死区，开关管的导通压降、开通关断过程也会引入非线性，量级一般比死区小。

Simulink 里模拟死区，有两种做法。

一种是用详细开关模型，拿 Simscape Electrical 的 MOSFET 或 IGBT 搭三相桥，设置死区时间。这种模型最真实，但跑得慢，一般只研究开关过程本身时才用。

另一种更适合验证控制算法：用平均值模型，在理想输出电压上叠加死区误差：
$$u_{out} = u_{ideal} + \Delta u$$
$\Delta u$ 按上面的式子、根据电流符号计算。它能反映死区带来的电压误差和 6 次谐波，又不拖慢仿真，日常验证算法够用了。

## 6、电流采样误差的模拟

第三个是电流传感器。

仿真里，我们常常把电机的真实电流拿去做反馈。真实控制器拿到的电流，是经过传感器、采样电路、ADC 转换之后的值，和真实电流总有差距，主要有四项。

一是零漂。传感器和运放都有失调电压，输出会整体偏移一个固定的量：
$$i_{meas} = i_{real} + i_{offset}$$
零漂会让 dq 轴电流出现基波误差，进而带来转矩脉动，严重时低速下能听到明显的嗡嗡声。

二是增益偏差。放大电路的电阻精度、传感器灵敏度的误差，会让测量值比真实值按比例偏大或偏小：
$$i_{meas} = k \cdot i_{real}, \quad k \neq 1$$
增益偏差主要影响电流幅值的准确性。

三是底噪。采样电路的噪声、ADC 的量化噪声，都会叠加进来，可以近似成一个白噪声：
$$i_{meas} = i_{real} + n$$
底噪大小与硬件性能相关，也决定了电流环能做到多高的带宽。带宽越高，噪声放大越厉害。

四是采样时刻。电流采样不是随时都能采的。在 PWM 周期里，开关管在不停斩波，电流上叠加着开关纹波。要想采到接近平均值的电流，要在开关动作的中点采样，比如三角载波的顶点或谷点。如果采样时刻没对准，采到的是纹波上的某一个点，误差会很大。三电阻采样还有采样窗口的限制，低调制比时甚至采不到电流。

Simulink 里，零漂加一个常数偏置，增益偏差乘一个不等于 1 的系数，底噪用 Band-Limited White Noise 加白噪声，采样时刻用 Zero-Order Hold 在指定的载波时刻采样。四项叠加起来，反馈通道与真实控制器比较接近。

## 7、速度信号的提取与滤波

第四个是速度信号。

位置传感器（编码器、旋变、磁编码器）给出的是位置，不是速度。真实控制器里的速度，是用位置差分算出来的：
$$\omega(k) = \frac{\theta(k) - \theta(k-1)}{T_s}$$
差分是个高通环节，对噪声很敏感。位置信号上哪怕只有一点量化误差或噪声，除以很小的 $T_s$，都会被放大。所以真实控制器里，差分出来的速度一定要滤波才能用，最常见的是加一阶低通：
$$H(s) = \frac{1}{\tau s + 1}, \quad \omega_c = \frac{1}{\tau}$$
截止频率 $\omega_c$ 的选取是个折中：太高，噪声滤不干净；太低，相位滞后大，速度环带宽上不去。

Simulink 里，先对位置做离散差分（Discrete Derivative），再接一个一阶低通（Discrete Filter）。这个滤波器不是装饰，真实系统里确实有这一环；仿真里不加，速度环的表现会偏乐观。

## 8、把四个环节串起来

把上面四个环节串起来，一个贴近实际的仿真模型大致是这样：控制器算出的电压指令，先经过一拍延迟，再进逆变器模型（叠加死区误差），作用到电机上；电机的真实电流经过传感器模型（零漂、增益、底噪、采样时刻）变成反馈电流；位置信号经过差分和低通滤波变成反馈速度。

和理想仿真相比，多了这些：一拍延迟、死区、传感器误差、速度滤波。每一项单独看都不大，叠在一起会明显改变系统的动态特性：相位裕度下降，电流纹波增大，低速抖动加剧。

### 一、Clarke 变换

```matlab
function [ialpha, ibeta] = fcn_clarke(ia, ib, ic)
%#codegen
ialpha = (2/3) * (ia - 0.5*ib - 0.5*ic);
ibeta  = (2/3) * (sqrt(3)/2*ib - sqrt(3)/2*ic);
```

### 二、Park 变换

```matlab
function [id, iq] = fcn_park(ialpha, ibeta, theta)
%#codegen
id =  ialpha*cos(theta) + ibeta*sin(theta);
iq = -ialpha*sin(theta) + ibeta*cos(theta);
```

### 三、电流调节器（d 轴）

```matlab
function ud = fcn_pi_d(ed)
%#codegen
Ld  = 0.004987;
Rs  = 0.9585;
Ts  = 0.0001;
Udc = 300;

Kp = Ld/(3*Ts);
Ki = Rs/(3*Ts);
Umax = Udc/sqrt(3);
int_lim = Umax/Ki;

persistent int_d
if isempty(int_d)
    int_d = 0;
end

int_d = int_d + ed*Ts;

if int_d >  int_lim, int_d =  int_lim; end
if int_d < -int_lim, int_d = -int_lim; end

ud = Kp*ed + Ki*int_d;

if ud >  Umax, ud =  Umax; end
if ud < -Umax, ud = -Umax; end
```

### 七、SVPWM

```matlab
function [Ta, Tb, Tc] = fcn_svpwm(ualpha, ubeta, Udc)
%#codegen
SQRT3     = 1.73205080757;
SQRT3_INV = 0.57735026919;

volAlphaNorm = ualpha/Udc*SQRT3;
volBetaNorm  = ubeta/Udc*SQRT3;

voltU = volAlphaNorm;
voltV = -0.5*volAlphaNorm + SQRT3*0.5*volBetaNorm;
voltW = -0.5*volAlphaNorm - SQRT3*0.5*volBetaNorm;

voltMax = max([voltU, voltV, voltW]);
voltMin = min([voltU, voltV, voltW]);
voltZero = -0.5*(voltMax + voltMin);

dutyU = SQRT3_INV*(voltU + voltZero) + 0.5;
dutyV = SQRT3_INV*(voltV + voltZero) + 0.5;
dutyW = SQRT3_INV*(voltW + voltZero) + 0.5;

Ta = min(max(dutyU, 0), 1);
Tb = min(max(dutyV, 0), 1);
Tc = min(max(dutyW, 0), 1);
```
